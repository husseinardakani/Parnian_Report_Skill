# Reporting validation

- [ ] Reconcile metrics against an independent query or synthetic fixture at row, subtotal and total levels.
- [ ] Test missing values, duplicates, empty results, grain, and relationship propagation.
- [ ] Test combined filters, search, sorting, paging, drill-down, Jalali boundaries, and timezone conversion.
- [ ] Test direct API, visual, drill-through, and export permissions with restricted identities.
- [ ] Measure load, refresh, query, and export performance at representative volumes.
- [ ] Compare PDF, Excel, CSV, and print output with the authorized selection and KPI definitions.
- [ ] Inspect RTL, mixed-script text, keyboard flow, contrast, labels, status changes, and browser/device behavior.
- [ ] Record target versions, data fixture, expected and observed results, evidence, and unresolved limitations.
