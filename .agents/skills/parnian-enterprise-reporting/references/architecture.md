# Architecture and UX

Choose an operational or detailed tabular report for daily work, an analytical, comparative or trend view for investigation, a management or executive dashboard for oversight, an exception view for action, a drill-down for tracing totals, or a formal printable report for distribution. Record the decision supported, grain, freshness, performance budgets, data contract, and source of truth.

For ASP.NET Core / .NET 10 and Blazor Web App, reuse authorized application endpoints and a common query/filter contract. For SharePoint SPFx, verify the supported SPFx, Node and API versions for the exact SharePoint 2019 or Subscription Edition patch level. For SQL Server discovery, inspect approved schema/metadata with read-only credentials. Use parameterized filters, inspect representative plans and cardinalities, and check paging order and limits. Apply authorization at the data boundary for every detail, aggregate, drill-down, and export. Budget load, refresh, and export separately.

Use ISO 9241-210 to ground design in users and tasks, Nielsen's usability heuristics to review interactions, Fluent 2 patterns and Carbon enterprise patterns where appropriate, and WCAG 2.2 AA for accessibility. Use Persian RTL and consistent Persian-capable typography. Provide responsive layouts, meaningful labels and legends, visible keyboard focus, accessible chart summaries or data tables, and status feedback. Add relevant filters, sorting, grouping, drill-down, search, and paging or virtualization. Design empty, loading and error states with contextual validation. Use icon actions with accessible names and tooltips for edit, copy, and delete where applicable.

Show and accept Jalali dates in pickers, charts, tables, timelines and exports. Define the business timezone, translate chosen dates into a start-inclusive/end-exclusive range at local calendar boundaries, and convert those boundaries to the backend representation. ISO/Gregorian/UTC is suitable for storage and transport. Check Nowruz, leap Esfand, first/last day of month or year, and records adjacent to a boundary. Sort by the underlying date, and use consistent date captions and filter summaries across targets.
